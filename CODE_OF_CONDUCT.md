# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct.

In short: be respectful and constructive. Harassment, personal attacks, and
demeaning behavior are not welcome. Assume good faith and help keep discussion
useful for everyone.

To report a concern, open a private report via the repository's Security tab, or
contact the maintainer through GitHub. Reports will be handled discreetly and in
good faith. The full text of the pledge, standards, and enforcement guidelines is
at the link above.
